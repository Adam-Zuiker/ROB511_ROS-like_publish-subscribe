# Project 1 starter directories

This folder contains **four alternatives**, not one submission. Choose one:
`python/`, `c/`, `cpp/`, or `rust/`.

Complete the selected directory, then create `submission.tar.gz` from the
contents of that directory so its `Makefile` is at the archive's project root.
Do not submit this parent `starter/` directory or all four starters together.

See `spec/PROJECT1_ASTAR.md` and `spec/ROSBRIDGE_PROTOCOL.md` in the course
starter bundle for the public requirements. `tools/map_to_rosbridge.py` is an
optional external-client helper for local map testing.
